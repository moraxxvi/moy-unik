# Мой уник

Удобная страница поверх Canvas LMS Университета Туран: дедлайны, оценки, калькулятор итоговой оценки и GPA в одном месте — на компе и на телефоне.

## Что умеет

- **Дедлайны** — всё, что нужно сдать, по срокам: просрочено, сегодня, завтра, неделя, позже. Сданное скрыто по умолчанию. Для каждого задания видно, сколько оно добавит к итогу.
- **Предметы** — оценки по каждой работе, отзывы преподавателей, тесты (время, попытки).
- **Калькулятор** — итог по формуле РК1 × 0,3 + РК2 × 0,3 + Экзамен × 0,4. Несданное в срок считается нулём. Если РК ниже 50 — предупреждение о недопуске к сессии.
- **«Не моё»** — убрать задание, которое препод выложил для другой группы: оно пропадёт из дедлайнов и не будет считаться в РК.
- **GPA** — по проценту из Canvas, с округлением до целого, как в АСУ. Кредиты вписываются вручную.
- **Что нового и объявления** — свежие оценки, изменения сроков, объявления преподавателей.
- **Напоминания в Telegram** — утренняя сводка, напоминание перед сроком, новые оценки (по желанию).

## Как устроено

| Файл | Что делает |
|---|---|
| `Code.gs` | Вся логика: запросы в Canvas, сбор данных, напоминания. Работает в Google Apps Script. |
| `index.html` | Страница целиком: вид, расчёты, калькулятор, GPA. |
| `appsscript.json` | Настройки веб-приложения Google: доступ для учебных аккаунтов, запуск от имени студента. |
| `server.js` | Запускает тот же `Code.gs` на компе — для проверки изменений до выкладки. |
| `deploy.sh` | Заливает изменения в Google и обновляет сайт (ссылка не меняется). |
| `Запустить.command` | Двойной клик — локальная версия открывается в браузере. |

Сайт работает от имени того, кто его открыл, и пускает только учебные аккаунты. Каждый студент вставляет свой маркер доступа Canvas один раз; маркер хранится в его собственном Google-аккаунте и уходит только в Canvas. Данные Canvas только читаются.

## Запуск на компе

Нужен [Node.js](https://nodejs.org). Двойной клик по `Запустить.command` или:

```bash
node server.js
```

Страница откроется на `http://localhost:8787`. Маркер Canvas сохранится в `canvas-token.txt` — этот файл в git не попадает.

## Выкладка

```bash
./deploy.sh "что изменилось"
```

Нужен вход в Google-аккаунт, где лежит проект Apps Script (`clasp --user uni login`).

## Маркер Canvas

Canvas → Аккаунт → Настройки → «Новый маркер доступа». После подключения маркер **не удаляй и не пересоздавай** — сайт хранит именно его, и он сразу перестанет работать.
