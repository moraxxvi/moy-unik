# Мой уник

Своя страница поверх Canvas LMS Университета Туран. Открываешь её и сразу видишь главное: что сдавать, какие оценки, хватает ли на допуск к сессии, какой GPA. Работает на компе и на телефоне (иконка на главном экране, меню снизу, как в приложении).

Пользоваться может любой студент с почтой `@turan-edu.kz` — каждый входит под своей учебной почтой и видит только свои данные.

## Что решает

| Боль | Как стало |
|---|---|
| Каждый раз логиниться в Canvas | Маркер вставляешь один раз, дальше страница просто открывается — и на телефоне тоже |
| Дедлайны разбросаны по курсам | Один список по срокам: просрочено, сегодня, завтра, неделя, позже; сверху отсчёт до ближайшего |
| Непонятно, что важнее сдать | У каждого задания видно, сколько оно добавит к итогу |
| Преподы выкладывают задания для других групп | Кнопка «не моё»: задание пропадает из дедлайнов и не считается в РК |
| Не знаешь, хватает ли на допуск | РК считаются сами, несданное в срок — как 0; если РК ниже 50 — красное предупреждение о недопуске |
| Сколько надо на экзамене | Калькулятор по формуле РК1 × 0,3 + РК2 × 0,3 + Экзамен × 0,4: сколько уже есть, сколько нужно на экзамене и за оставшиеся работы |
| Экзамен заменяет командный проект (СРО) | Можно выбрать, из какой группы заданий берётся экзамен |
| Оценки и отзывы спрятаны глубоко | Раскрываешь предмет — все работы с баллами, штрафами за опоздание и комментариями преподавателей |
| Непонятный GPA | GPA по проценту Canvas, с округлением до целого, как в АСУ, и подсказкой «в АСУ, скорее всего, 80» |
| Пропускаешь изменения | Лента «Что нового»: новые оценки, перенесённые сроки, объявления |
| Скроллить на телефоне долго | Меню разделов; сданное скрыто по умолчанию |

## Возможности

- **Дедлайны** — фильтр по предмету, тесты с лимитом времени и числом попыток, кнопка «не моё».
- **Предметы** — оценки по каждой работе по группам Canvas (Рейтинг 1, Рейтинг 2, экзамен), отзывы преподавателей, преподаватель и программа курса.
- **Калькулятор** — РК и экзамен из Canvas с возможностью вписать своё число, цель по итогу, предупреждение о недопуске.
- **GPA** — прошлые семестры, прогноз на текущий и вместе; кредиты вписываются вручную, пробное тестирование по умолчанию не считается.
- **Что нового и объявления** — свежие оценки, изменения сроков, объявления за последние недели.
- **Напоминания в Telegram** — утренняя сводка, напоминание за 3 часа до срока, новые оценки (по желанию).

## Как устроено

| Файл | Что делает |
|---|---|
| `Code.gs` | Вся логика: запросы в Canvas, сбор данных, напоминания. Работает в Google Apps Script. |
| `index.html` | Страница целиком: вид, расчёты, калькулятор, GPA, меню. |
| `appsscript.json` | Настройки веб-приложения: доступ для учебных аккаунтов, запуск от имени студента. |
| `server.js` | Запускает тот же `Code.gs` на компе — чтобы проверить изменения до выкладки. |
| `deploy.sh` | Заливает изменения в Google и обновляет сайт (ссылка не меняется). |
| `Запустить.command` | Двойной клик — локальная версия открывается в браузере. |

- **Без сервера и оплаты.** Сайт — веб-приложение Google Apps Script на учебном аккаунте; вход — через учебную почту.
- **Маркер Canvas хранится в Google-аккаунте самого студента.** Он уходит только в Canvas, паролей сайт не видит, данные только читает.
- **Если маркер сломался, сайт не выкидывает.** Показывает последние загруженные данные и просит новый маркер прямо сверху, с понятной причиной.
- **Один код для обеих версий.** Локальный `server.js` подменяет сервисы Google на свои и запускает тот же `Code.gs`.

## Запуск на компе

Нужен [Node.js](https://nodejs.org). Двойной клик по `Запустить.command` или:

```bash
node server.js
```

Страница откроется на `http://localhost:8787`. Маркер Canvas сохранится в `canvas-token.txt` — этот файл в git не попадает.

## Выкладка

```bash
./deploy.sh "что изменилось"
```

Нужен вход в Google-аккаунт, где лежит проект Apps Script (`clasp --user uni login`).

## Маркер Canvas

Canvas → Аккаунт → Настройки → «Новый маркер доступа». После подключения маркер **не удаляй и не пересоздавай** — сайт хранит именно его, и он сразу перестанет работать.

## Ограничения

- **Маркер нужно создать один раз.** Обычный вход «через Canvas» без маркера требует ключа разработчика (Developer Key) от IT-отдела университета.
- **АСУ не подключена** — транскрипт выдают только на бумаге, поэтому кредиты вписываются вручную. Оценки и GPA в АСУ могут немного отличаться от Canvas.
- **Шкала GPA** — стандартная казахстанская (95+ = A 4,0 … 50 = D 1,0, ниже 50 = F).
- **Формула итога и порог допуска** (50 по каждому РК) — как в Туране; на других факультетах могут отличаться.
- **WhatsApp-напоминаний нет** — для этого нужен платный бизнес-доступ Meta.
