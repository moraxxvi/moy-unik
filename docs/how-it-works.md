# Как это работает и безопасность

«Мой уник» — страница, которая показывает данные студента из Canvas: дедлайны, оценки, объявления. Работает на Google Apps Script, доступна только с учебной почтой `@turan-edu.kz` и запускается от имени того, кто её открыл. Эта страница описывает, что именно делает код, и совпадает с разделом «Как это работает» на самом сайте.

## Что страница читает из Canvas

Только запросы на чтение (GET), и только про курсы и работы самого студента.

| Что | Запрос к Canvas API |
|---|---|
| Имя | `/users/self` |
| Курсы, итоговый процент, семестр, преподаватели, программа курса | `/courses` |
| Ближайшие дедлайны | `/planner/items` |
| Лента событий (новые оценки, перенос сроков) | `/users/self/activity_stream` |
| Работы, оценки и отзывы преподавателей | `/courses/{id}/students/submissions` (только свои) |
| Группы заданий | `/courses/{id}/assignment_groups` |
| Тесты (время, попытки) | `/courses/{id}/quizzes` |
| Объявления | `/announcements` |

Нагрузка: около 25 запросов на одно обновление (при 7 курсах). Страница обновляется при открытии, при возврате к ней (если данным больше 2 минут) и раз в 10 минут, пока открыта.

## Чего страница не делает

- Не отправляет работы, не пишет сообщения и комментарии, ничего не меняет и не удаляет в Canvas: в коде нет ни одного запроса на запись к Canvas.
- Не просит пароль от Canvas или Google.
- Не читает данные других студентов.
- Не собирает статистику: в коде нет аналитики, трекеров и счётчиков.

## Где хранятся маркер и данные

- **Маркер Canvas** — в личных свойствах скрипта (User Properties) Google-аккаунта самого студента. У автора проекта нет ни своего сервера, ни базы пользователей.
- **Настройки** (отметки «не моё», кредиты, цели) — там же.
- **В браузере** хранится последняя загруженная копия данных (чтобы страница не пустела, если маркер перестал работать), выбранный раздел и галочка «скрыть сданное». Всё это стирается очисткой данных сайта.
- **Шрифт** Inter загружается с Google Fonts. Больше ничего внешнего страница не подгружает.
- **Telegram** — по желанию и по умолчанию выключен. Если студент подключит своего бота, названия заданий, предметы и оценки отправляются в этот бот. Без подключения в Telegram ничего не уходит.
- Google ведёт собственный технический журнал запусков скрипта, как для любого скрипта.

## Ограничения, о которых стоит знать

- **Маркер Canvas мощнее, чем нужно странице.** Созданный вручную маркер даёт те же права, что у студента, а Canvas не позволяет ограничить такой маркер «только чтением». Страница использует его только для чтения, но сам маркер нельзя никому передавать.
- **Нужно доверять автору.** Код запускается от имени студента, а проект принадлежит автору, поэтому технически автор может изменить код. Именно поэтому код открыт: <https://github.com/moraxxvi/moy-unik>. Права, которые скрипт просит у Google при первом входе: запросы к внешним сайтам (`script.external_request`) и запуск по расписанию (`script.scriptapp`, нужен только для напоминаний в Telegram).

## Как отозвать доступ

1. На сайте: «Ещё» → «Отключить Canvas на этом аккаунте» — маркер удаляется из аккаунта Google.
2. В Canvas: Аккаунт → Настройки → «Утвержденные интеграции» → корзина рядом с маркером. Сайт маркер в Canvas не удаляет, это нужно сделать самому.
3. По желанию: в настройках аккаунта Google (Безопасность → сторонние приложения) убрать доступ скрипта.

## Как станет лучше

Маркеры — временное решение. Правильный вариант — ключ разработчика (Developer Key) и вход через OAuth2: студент входит на странице Canvas, пароль и маркеры не нужны, права ограничены чтением, а администраторы могут отозвать доступ централизованно.

Вопросы и замечания по безопасности — в разделе Issues репозитория: <https://github.com/moraxxvi/moy-unik/issues>.
